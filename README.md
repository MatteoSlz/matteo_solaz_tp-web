# Installation et lancement
1: Téléchargez ou clonez ce dépôt sur votre machine 
"https://github.com/MatteoSlz/matteo_solaz_tp-web"

2: Ouvrez le dossier dans un logiciel comme VS Code ou autre.

3: Faites start index.html dans le terminal pour ouvrir le projet directement dans votre navigateur web

# Synopsis du projet web : 

Une histoire interactive en HTML/CSS dans laquelle vous incarnez le manager de la Karmine Corp. Prenez les bonnes décisions concernant le roster pour mener votre équipe jusqu'au titre de champion et plus dans une dizaine de pages connectées.


# Fonctionnalités
- Plusieurs embranchements scénaristiques lors du jeu qui mènent tous à différentes finalités 

- Plusieurs fins possibles 

- Des images et vidéos pour rendre le jeu vivant 

- Un arbre de navigation en PDF consultable qui décrit la forme du projet

# Langages utilisés : 
- HTML
- CSS
